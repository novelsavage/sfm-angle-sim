# 撮影ルート

スマホで部屋・多目的トイレをフォトグラメトリするときの、移動・視線・高さを学ぶWebガイド。

- Three.jsの模式図：5段階の撮影動作、再生／停止、位置スライダー、俯瞰／平面／スマホ視点、高さ調整。
- 公開3Dモデル4件：ワンルームの設計モデル2件、東京都による都庁前駅バリアフリートイレの実測スキャン2件。公式Sketchfabビューアで表示。
- KIRI Engine Basic／Polycam Freeの条件と動画取り込み手順。対象端末はPixel 8a、iPhone 13 mini、iPhone 14、iPhone 17、Nothing Phone (3a)。
- PC／スマホ表示、キーボード操作、チェックリスト、出典表示、外部ビューアの読込失敗への対応。

## 開発

検証環境はNode.js 24、npm 11。既存のチェックアウトを使います。

```sh
npm ci
npm run dev
```

開発サーバーの標準ポートは5173。ビルド成果物は `dist/`。

## GitHub Pages

`main`へのpushで `.github/workflows/pages.yml` がテスト・ビルド・Pages公開を実行します。Actionsの実行画面から再実行もできます。公開対象は `dist/` だけです。

Pagesの配置先は公式 `configure-pages` アクションの `base_path` 出力をViteへ渡します。ローカルで同じパスを検証する場合は `BASE_PATH=/sfm-angle-sim npm run build` を実行します。

初回はワークフローからPagesを有効化します。権限やプランによって失敗する場合は、リポジトリの Settings → Pages → Source で GitHub Actions を選択してください。非公開リポジトリのPagesはGitHubの契約プランによって利用できない場合があります。

## 検証

```sh
npm run build
npm test
npm run test:browser
```

ブラウザテストは開発サーバーを起動した状態で実行します。既定では `/usr/bin/chromium` を使用し、別のChromiumは `CHROMIUM_PATH` で指定できます。テスト画面は無視対象の `test-results/` に保存します。

## 使い方

1. ワンルーム／多目的トイレと参考モデルを選ぶ。
2. 撮影段階を選び、再生する。高さ・視点・進行位置を操作する。
3. 「3Dモデルを読み込む」で公開モデルを回転し、設備の死角を観察する。
4. 使用するスマホとアプリを選び、無料枠と取り込み手順を確認する。

## 範囲と制約

動作図は自作の模式図で、選択した公開モデルの間取りを再現したものではありません。実測メッシュ上に経路を重ねる機能、衝突判定、カバレッジ計算、SfM処理、寸法測定はありません。表示速度・画角は説明用です。

実測トイレの元データはLiDARによるものです。これを参考として観察することと、今回スマホ写真・動画で撮影する手法は区別しています。ワンルーム2件は設計モデルで、実在する部屋の実測とは紹介していません。

モデルは公式の外部埋め込みを使い、メッシュを再配布しません。外部通信とWebGL対応が必要です。クラウドのヘッドレスChromiumでは外部ビューアから `No Hardware Support for Webgl` が返るケースを確認しています。読み込み成功を装わず、再試行と配布元リンクを表示します。模式図と手順は引き続き使用できます。

無料版仕様は2026年9月30日の公式ページに基づきます。KIRI無料Photo Scanへの動画直接入力は確認できていないため、動画から写真を抽出する経路を案内します。端末5機種での実機検証、実写動画の再構成・精度検証は未実施です。
